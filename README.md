# Weather App

## Description
This project is a weather application that helps users check the current weather for a city or location. It gets weather data from an online API and shows information like temperature, humidity, wind speed, and the current weather condition.

## Features
- Search weather by city name
- Display the current temperature
- Show humidity and wind speed
- Show weather conditions such as sunny, cloudy, or rainy
- Simple and easy-to-use layout

## Technologies Used
- HTML
- CSS
- JavaScript
- Weather API

## How to Run
1. Open the project folder in your editor.
2. Make sure all project files are in place.
3. Open the main HTML file in a browser, or start a local server.
4. Enter a city name to see the weather.
